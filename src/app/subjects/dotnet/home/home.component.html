How to Use This Site

  1. Read the topic top-to-bottom — don't jump to code first. Understand why before how.
  2. Predict the output before clicking See Output. This is the closest thing to a real coding round.
  3. Re-read the interview questions the day before any interview. They are the actual questions you'll face.
  4. Build a project alongside — see Phase 7. Theory without project is forgotten in 2 weeks.
