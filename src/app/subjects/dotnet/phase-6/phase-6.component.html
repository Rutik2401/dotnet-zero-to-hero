DevOps & Deployment

Code is only half the job — shipping it to production is the other half. This phase covers the things every .NET dev (even a fresher) is expected to know in interviews — Git workflow, GitHub PRs, CI/CD with GitHub Actions, Docker, IIS hosting, Azure App Service, and how to handle config & secrets safely. No DevOps engineer-level depth, just what a developer must know to be useful from day one on a real team.
